Issues & Notes

  • Relative Path:

    The href="sample.pdf" is a relative path. This works only if sample.pdf is located in the same directory as this HTML file.

  • Browser Context:

    If this HTML is opened using Selenium with driver.get(), the browser must be able to resolve the relative path correctly.

  • Portability:

    Relative paths are preferred over absolute paths because they work across different machines, CI pipelines, and operating systems.

  • PDF Loading:

    Some browsers may open PDFs in a built-in viewer instead of downloading them, which is expected behavior.

  • Language Attribute:

    The lang attribute in the <html> tag is empty. It should be set (for example: lang="en") for accessibility and standards compliance.
